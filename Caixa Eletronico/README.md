# Sistema Bancário em Python

Projeto desenvolvido durante meus estudos de **Python**, com o objetivo de praticar estruturas de repetição, condicionais, entrada de dados e operações matemáticas.

## Sobre o projeto

O programa simula um sistema bancário simples através de um menu no terminal.

O usuário pode:

* Consultar o saldo
* Realizar depósitos
* Realizar saques
* Ver o novo saldo após as operações

## Funcionalidades

### 1. Consultar saldo

Permite verificar o saldo disponível na conta.

### 2. Depositar

O usuário informa o valor que deseja depositar e o programa calcula o novo saldo.

### 3. Sacar

O usuário informa o valor do saque e o programa verifica se existe saldo suficiente para realizar a operação.

### 4. Sair

Encerra a execução do programa.

## Conceitos praticados

Neste exercício foram utilizados:

* `while True`
* `if`
* `input()`
* `print()`
* Conversão de tipos com `int()` e `float()`
* Operações matemáticas
* Variáveis e acumuladores
* F-strings
* Estruturas condicionais
* Criação de menus interativos

## Exemplo

```text
[1] Consultar saldo
[2] Depositar

Digite um valor para acessar o menu: 2
```
